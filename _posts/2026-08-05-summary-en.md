## [Monodratic: Learned Product-Hash Routing for Sparse Causal Attention](https://www.reddit.com/r/MachineLearning/comments/1vg3jda/monodratic_learned_producthash_routing_for_sparse/) ⭐️ 8.0/10

Monodratic introduces a sparse causal-attention architecture that uses learned product-hash routing to assign source blocks to bounded posting lists and select a fixed number of remote blocks per query. In synthetic associative-recall tests, it achieved 99.35% mean accuracy \(763/768\) with only 2 selected remote blocks, and recovered all errors when forcing the target block, reaching 768/768. This work addresses the quadratic complexity of standard attention, potentially enabling more efficient transformers for long sequences. The strong associative-recall results suggest that learned routing can maintain high accuracy while drastically reducing the attention budget, which could impact the design of future efficient transformer architectures. The implementation is a stateless \[batch, sequence, width\] -&gt; attention-delta mixer, leaving normalization, residuals, and feed-forward layers to the host model. It uses exact causal softmax over selected tokens, and the packed CPU routing implementation showed a fitted timing exponent of 0.993 from 4,096 to 32,768 tokens. Limitations include synthetic experiments, portable PyTorch \(not a fused kernel\), and no claims of natural-language quality or deployment speed.

reddit · r/MachineLearning · /u/dttdrv · Aug 5, 10:28

**Background**: Sparse attention mechanisms aim to reduce the quadratic cost of standard attention by focusing on a subset of tokens. Associative recall is a key capability in transformers, where the model retrieves stored information based on cues. Product hashing is a technique to map high-dimensional vectors to compact codes, which can be used for efficient routing in attention.

The vulnerability was introduced in Coldcard firmware version 4.0.0 in March 2021, causing devices to skip the hardware random number generator and fall back to predictable software-based key generation seeded by nonsecret chip data. The attack involved a 25-minute sweep that drained 594 BTC, and later a 41-minute sweep that stole $70 million, with total losses now exceeding $130 million.

**Background**: Hardware wallets are physical devices designed to securely store cryptocurrency private keys offline, protecting them from online threats. Coldcard, manufactured by Toronto-based Coinkite, is a popular Bitcoin hardware wallet known for its security features. The vulnerability exploited a flaw in the random number generator, which is crucial for generating unpredictable private keys; if predictable, attackers can derive private keys and steal funds.
