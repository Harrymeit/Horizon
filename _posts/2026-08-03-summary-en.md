## [Cloudflare Workers Now Support Inbound TCP and gRPC](https://blog.cloudflare.com/grpc-workers/) ⭐️ 8.0/10

Cloudflare Workers and Containers now support inbound TCP connections via Spectrum, enabling direct socket forwarding to Durable Objects and Containers. This allows developers to run full-duplex gRPC applications or use automatic gRPC-to-gRPC-web translation directly within Workers. This update significantly expands Cloudflare Workers&\#x27; capabilities for building real-time, full-duplex applications, which was previously limited by the lack of inbound TCP support. It enables developers to build gRPC-based services at the edge without managing separate proxies, potentially reducing latency and simplifying deployment. The feature leverages Cloudflare Spectrum for TCP proxying, which can also act as a TCP load balancer and supports PROXY Protocol v2. The automatic gRPC-to-gRPC-web translation eliminates the need for a separate proxy like Envoy or Caddy, which is typically required for web clients to communicate with gRPC servers.

rss · Cloudflare Blog · Aug 3, 13:00

**Background**: gRPC is a high-performance RPC framework that uses HTTP/2 and Protocol Buffers, but web browsers cannot directly send gRPC requests due to limitations in HTTP/2 support. gRPC-web is a protocol that allows browser clients to communicate with gRPC servers, typically requiring a proxy to translate between the two protocols. Cloudflare Workers is a serverless edge computing platform, and Durable Objects provide stateful serverless functions that can handle concurrent requests and WebSockets.

## [Cloudflare Optimizes KV Cache and Weight Quantization for Frontier Model Serving](https://blog.cloudflare.com/smaller-faster-safer-models/) ⭐️ 8.0/10

Cloudflare published a technical blog post detailing how it quantizes KV caches and model weights to serve frontier models like Kimi and GLM faster, cheaper, and with integrity checks. The post describes techniques for reducing GPU memory usage while maintaining model performance. This is significant because serving large language models efficiently is a major bottleneck for AI infrastructure. By reducing GPU memory requirements, Cloudflare&\#x27;s techniques could lower costs and improve scalability for AI deployments, benefiting developers and enterprises that rely on such models. The post covers quantization of KV caches and model weights, along with integrity checks to ensure output correctness. It likely discusses specific methods such as per-channel key quantization, pre-RoPE key quantization, and non-uniform quantization, as referenced in related research.

rss · Cloudflare Blog · Aug 3, 13:00

**Background**: Quantization reduces the precision of numerical values in a model, such as from 32-bit floats to 8-bit integers, to save memory and speed up inference. KV cache stores intermediate key-value pairs during generation, which can consume significant GPU memory for long contexts. Techniques like KVQuant and mixed-precision quantization help mitigate memory pressure while preserving accuracy.

## [Cloudflare Workers Now Support Cross-Language RPC Between Python and JavaScript](https://blog.cloudflare.com/python-workers-rpc/) ⭐️ 8.0/10

Cloudflare Workers now enables cross-language RPC between Python and JavaScript, allowing live object references and method calls without defining APIs, schemas, or serialization code. This extends the previously announced JavaScript-native RPC to support Python Workers. This simplifies multi-language development on serverless platforms, reducing boilerplate and enabling seamless integration between Python and JavaScript services. It could accelerate adoption of polyglot architectures and improve developer productivity in the Cloudflare ecosystem. The RPC system requires a compatibility date of 2024-04-03 or later, or the &\#x27;rpc&\#x27; compatibility flag. It works via service bindings, where Workers can extend the WorkerEntrypoint class and expose public methods for direct calls.

rss · Cloudflare Blog · Aug 3, 13:00

**Background**: RPC \(Remote Procedure Call\) allows a program to execute code on another machine or process as if it were local. Cloudflare Workers is a serverless platform that runs JavaScript and, more recently, Python. Previously, cross-language communication required defining APIs and serialization, but the new RPC system eliminates that overhead.
